# VibeCheck Survey

Phone web page for VibeCheck surveyors: find, edit and add places in Sulaymaniyah,
with names in Kurdish, Arabic and English, logos and photos.

Open: https://hanasa-vibecheck.github.io/vibecheck-survey/

Source lives in the main (private) VibeCheck repository under `survey/`; this copy is published with GitHub Pages.
Uses the public Supabase key only; all data access is protected by database rules.
